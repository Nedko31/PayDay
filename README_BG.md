# PayDay — Android + AdMob test project

Този архив преобразува последната PWA версия на PayDay в Android проект чрез Capacitor и добавя native AdMob банер.

## Какво е настроено

- Запазени са оригиналните екрани, данни, петте езика и бутоните за приход/разход.
- AdMob App ID е добавен в Android конфигурацията чрез скрипт.
- Има конфигурация за реалния рекламен елемент PayDay_Banner.
- **По подразбиране се използва само официалният тестов банер на Google**: `ca-app-pub-3940256099942544/6300978111`.
- Реалният рекламен елемент не се заявява, докато `useTestAds` е `true`.
- Рекламите се заявяват само в native Android приложението и само когато устройството отчита интернет връзка.
- Добавен е UMP flow за съгласие; рекламата се показва само ако UMP върне `canRequestAds: true`.
- При загуба на интернет банерът се скрива; при възстановяване се прави нов опит.
- В настройките има бутон за скриване/показване на банера.
- PWA версията в браузър не заявява AdMob реклами.

## Важно преди компилация

`appId` в `capacitor.config.ts` е зададен като `bg.jorge.payday`. Ако вече имаш избран Android package name от предишния APK/AAB или ще използваш друг package name в Google Play, смени го **преди** `android:add`. Идентификаторът трябва да остане същият за всички бъдещи версии в магазина.

## Изисквания

- Node.js 22 LTS или съвместима версия
- Android Studio 2025.2.1 или по-нова
- Android SDK Platform API 24 или по-нова
- Интернет при първоначалната инсталация на npm пакетите и Gradle зависимостите

Този работен контейнер няма Android SDK/Android Studio и няма достъп до npm registry в момента. Затова тук не може да бъде компилиран или инсталиран APK. Архивът е Android source project, а не готов APK.

## Компилация на Windows

Отвори папката в терминал (PowerShell):

```powershell
npm install
npm run build
npm run android:add
npm run android:sync
npm run android:open
```

В Android Studio изчакай Gradle Sync и избери **Build → Build Bundle(s) / APK(s) → Build APK(s)**. За тест на телефон използвай debug APK.

Алтернативно, ако Android SDK/Gradle са правилно конфигурирани:

```powershell
cd android
.\gradlew.bat assembleDebug
```

APK файлът ще бъде в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Тестване

1. Инсталирай debug APK на Android устройство.
2. Дай интернет достъп.
3. При първо стартиране UMP може да покаже форма за съгласие (ако е налична/изисквана за AdMob профила).
4. След съгласие трябва да се зареди Google тестов банер в долната част.
5. Изключи интернет — банерът трябва да се скрие, а PayDay да продължи да работи.
6. Включи интернет — приложението трябва да опита отново.
7. Провери скриването/показването от настройките.

Не натискай тестовите реклами многократно и никога не използвай реалния рекламен елемент за собствени тестови кликове.

## Преминаване към реални реклами — по-късно

След като тестовият APK работи и приложението е готово за публикуване, в `web/src/main.js` промени:

```js
useTestAds: true
```

на `false`. Така ще се използва реалният рекламен елемент `ca-app-pub-7326151414179206/8537553188`. Не прави тази промяна за тестове или вътрешни кликове. Преди реални заявки настрой GDPR/ЕИП съобщението в AdMob → Поверителност и съобщения.

## Техническа бележка

AdMob Banner е нативен рекламен изглед, не HTML блок. Не е затваряем сам по себе си като interstitial; PayDay има отделен бутон в настройките, който скрива/показва банера чрез native SDK.
